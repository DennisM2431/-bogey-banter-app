# Bogey Banter v7.0 RC1.2 — The Mayhem Update

This build is based on the last working RC1.1.1 hotfix and has been rebuilt and validated as one complete package.

## Included

- 60 individual illustrated Chaos Card assets from the six approved card batches.
- The specifically approved original Chaos Combo artwork is Card 60.
- Full-screen 3D card-flip reveal.
- Chaos Combo draws exactly two unique bonus cards.
- Bonus cards cannot be another Chaos Combo or duplicate each other.
- All current-hole effects remain visible during scoring.
- Beer & Bump full-screen event every third hole when enabled.
- End-of-round individual-player voting.
- Team modes: one vote per team per category; all own-team players are greyed out.
- Singles: one vote per player per category; the voter is greyed out.
- Duplicate preset team names are disabled and validated.
- Eleven unique approved screen-background assets at 18% visibility.
- RC1.1.1 scoring, navigation, next-hole and safe-area fixes retained.

## Upload

Replace every repository file with this build and upload the complete `src` and `assets` folders.

No Firestore rules change is required from RC1.1.1.

After GitHub Pages deploys, fully close and reopen Bogey Banter so cache
`bogey-banter-v7-rc1-2-mayhem-final` loads.
