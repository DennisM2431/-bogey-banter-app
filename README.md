# Bogey Banter v5.2 — Concept 3 Rebuild

This release rebuilds the actual interface structure rather than applying another colour overlay.

## What changed

- New Concept 3 home screen with branded app header
- Neon tournament status strip
- Large Create, Join and Demo launch cards
- Rebuilt tournament builder with grouped controls
- New toggle design and shared-player setup
- Neon dashboard metric cards
- Rebuilt Lobby, QR, Leaderboard and Story layouts
- New bottom navigation component
- Larger full-screen chaos-card presentation
- Updated notification and status components
- Responsive mobile layouts for iPhone and Android

## Existing functionality retained

- Firebase live syncing
- Local QR code generation
- Singles: 2–4 players
- Shared-device Singles draw-first flow
- 2-player Ambrose: up to 12 teams
- 4-player Ambrose: up to 6 teams
- Paired scoring and score locks
- Floating admin approval alerts
- Beer & Bump
- Leaderboard, Story and awards

## Upload

Replace/upload all repository files together, then fully close and reopen Bogey Banter after GitHub Pages redeploys.
